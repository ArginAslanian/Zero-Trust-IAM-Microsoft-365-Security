# Zero Trust IAM & Microsoft 365 Security Hardening

An identity and access management security project focused on strengthening Microsoft 365 through Zero Trust principles, Conditional Access, MFA, SSO, and modern identity controls.

The project focused on reducing identity-based risk, improving authentication security, and strengthening access controls across the Microsoft 365 environment.

## Tech Stack

- Microsoft Entra ID
- Conditional Access
- Multi-Factor Authentication (MFA)
- Enterprise Applications
- SSO / SAML
- Microsoft 365 Defender
- Microsoft Defender for Cloud
- Microsoft Secure Score

## What I Worked On

- Reviewed existing identity and access controls across Microsoft 365
- Designed and implemented Conditional Access policies
- Enforced MFA for users and higher-risk access scenarios
- Configured and supported SSO for enterprise applications
- Applied Zero Trust access principles based on identity, device, and sign-in context
- Reviewed Microsoft Secure Score recommendations and identity security gaps
- Strengthened authentication and access policies to reduce unauthorized access risk
- Tested and validated policy behavior before broader enforcement
